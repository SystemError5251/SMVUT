SMVUT – Social Media Upload Tool

SMVUT (Social Media Upload Tool) lädt eigene, fertige Hochformat-Videos über die offiziellen Schnittstellen hoch: als YouTube Short, als Instagram Reel und als Entwurf in den TikTok-Posteingang. Die Veröffentlichung auf TikTok erfolgt anschließend von Hand in der TikTok-App.

Es ist ein privates Werkzeug des Entwicklers für die eigenen Konten, als Android-App und als Kommandozeilenprogramm. Es gibt keinen Server und kein Nutzerkonto bei SMVUT.

  • YouTube: YouTube Data API v3 (videos.insert)
  • Instagram: Instagram API mit Instagram Login (Content Publishing)
  • TikTok: Login Kit und Content Posting API (Upload als Entwurf)

SMVUT – Social Media Upload Tool (English)

SMVUT (Social Media Upload Tool) uploads the developer's own finished vertical videos through the official APIs: as a YouTube Short, as an Instagram Reel, and as a draft to the TikTok inbox. Posting on TikTok is then completed manually in the TikTok app.

It is a personal tool used by its developer for their own accounts, available as an Android app and a command-line program. There is no server and no SMVUT user account.
